「全案件JSON」は案件一覧・現在案件ID・各案件のDevelopment Project JSONを1ファイルにまとめます。復元時は現在状態をブラウザ内へ自動バックアップしてから、Development案件一覧を置き換えます。Game Projectには触れません。

    


    

      
Git保管 Development専用
Development Project JSONをGitへ保存・読込します。保存時はDevelopment Project JSONだけを更新します。package_manifest.jsonはソースコード整合性専用のため変更しません。Source ZIPは出力しません。Game / Studioデータ経路、既存GitHub同期、Development AI公開とは処理を共有しません。

      
入出力境界: Project本体の入出力先はGit上の development-project-data/ 配下だけです。Development Project JSONはソースコード用 package_manifest.json の対象外で、Git保存時にもmanifestを変更しません。Project本体とPATはブラウザStorageへ保存しません。Owner / Repository / Branchは未設定時に既定接続（kj2whvbzjn-hue / guild-adventure-studio / sub）を自動入力し、端末へ保存して再利用します。Git案件はSessionメモリで編集し、明示的に「現在Git案件を保存」でCommitします。

      

        

        

        

        
新規案件は development-project-data/<Project ID>.json を使用します。既存Git案件はRegistryに登録済みのGit Pathを優先し、旧Pathからの保存では別Pathの同一 workspace.id JSONを自動削除しません。
