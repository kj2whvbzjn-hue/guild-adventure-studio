# Build389 スキル定義・対象選択・攻撃倍率・回復検証

## 実装範囲

- スキル定義をデータとして参照する基盤。
- スキル種別 `damage` / `heal`。
- 対象規則 `enemy` / `ally` / `self` の検証基盤。
- 攻撃スキル倍率によるダメージ計算。
- 回復スキル倍率による回復量計算。
- 対象規則に反する実行の拒否。
- 構造化JSONLへの対象選択理由・倍率・結果の記録。

## 開発専用検証値

公式バランス値ではない。ExportおよびSaveへスキル検証データを出力しない。

- 検証攻撃力: 100
- パワーストライク倍率: 1.65
- 検証ヒール倍率: 1.50
- 検証MP: 9999
- 検証HP: 100000

## AI検証シナリオ

`skill_definition_target_damage_healing`

PASS条件:

1. スキルデータベースに通常攻撃・攻撃スキル・回復スキルが存在する。
2. 攻撃スキルは生存中の敵からHP比率が最も低い対象を選択する。
3. 攻撃力100 × 倍率1.65 = 165ダメージとなる。
4. 回復スキルは生存中の味方からHP比率が最も低い対象を選択する。
5. 攻撃力100 × 倍率1.50 = 150回復となる。
6. `ally` 対象の回復スキルを敵へ実行した場合 `INVALID_TARGET` で拒否する。
7. JSONLへ `SKILL_TARGET_SELECTED`、`SKILL_EXECUTED`、PASS/FAILを記録する。

## 影響範囲

- 開発用Battle Core検証のみ。
- Exportのスキルデータ変更なし。
- Save構造変更なし。
- 公式UI変更なし。
