# Build394 能力阻害状態付与スキル検証

## 実装範囲

- スキル定義から沈黙・暗闇・呪いを付与する検証スキル。
- 対象規則 `enemy` による敵単体への付与。
- 各スキルのMP消費と構造化実行ログ。
- 状態異常耐性による持続時間短縮。
- 沈黙による通常攻撃以外のスキル使用拒否。
- 暗闇による命中失敗判定。
- 呪いによる与ダメージ低下と回復効果低下。
- 各状態のTick持続時間更新。

## 開発専用検証値

公式バランス値ではない。ExportおよびSaveへ検証スキルを出力しない。

- `devSilence`: MP 14 / 沈黙 3000 Tick
- `devBlind`: MP 15 / 暗闇 3000 Tick / 検証MISS率 95%
- `devCurse`: MP 16 / 呪い 3000 Tick
- 対象状態異常耐性: 25%
- 期待持続時間: 2250 Tick
- 呪い中の与ダメージ倍率: 0.10
- 呪い中の回復効果倍率: 0
- 合計MP消費: 45

## AI検証シナリオ

`skill_ability_inhibition_application`

PASS条件:

1. 沈黙・暗闇・呪いの3スキルがスキルDBへ登録されている。
2. 各状態が耐性25%を反映して2250 Tickで付与される。
3. 沈黙中は通常攻撃以外のスキルが `SILENCED` で拒否される。
4. 暗闇中は指定乱数0.50で攻撃がMISSする。
5. 呪い中は攻撃100が10ダメージになり、回復効果が0になる。
6. 1 Tick進行後に残り時間が2249 Tickになる。
7. 3スキルのMP消費合計45が反映される。
8. JSONLへ `SKILL_STATUS_APPLIED`、`SKILL_EXECUTED`、PASS/FAILを記録する。
