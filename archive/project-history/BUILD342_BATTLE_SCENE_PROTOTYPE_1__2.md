# Build 342 — Battle Scene Prototype 1

## Positioning
- This is a visual prototype, not the final battle screen.
- It is based on Build 339 Battle Core 2 and does not include job-specific skills.
- Battle logic and visual presentation are separated.

## Added
- Symbol units for allies and enemies
- Idle motion
- Approach / attack / return motion
- Hit reaction and knockback
- Damage and MISS popups
- Animated HP bars
- Defeated pose
- Battle result overlay
- Scene speed and motion toggle
- One-action step button

## Preserved
- Save Data Version 1
- Character creation and job aptitude data
- Battle Core 2 Tick / Gauge / HP / normal attack / defeat / result
- GK Studio return link

## Not fixed as final specification
- Character artwork
- Background and formation coordinates
- Exact animation durations
- Damage and combat formulas
