# BUILD 471.0 正式リリース基盤

## 概要
BUILD 470.1〜470.9で追加した検証、ガイド、比率計算、計算カード、戦闘計算、システム接続、AI探索、品質ゲート、配布準備を正式リリース向けに統合した。

## 実施内容
- Studioバージョンを 1.42.0 に統一
- 開発ビルドを 471.0 に更新
- HTMLタイトル、画面表示、内部APP_VERSIONの不整合を修正
- リリースラベルを `build471.0-release` 形式へ変更
- 正式リリースマニフェスト、チェックリスト、リリースノートの出力名を統一
- package-build.json と studio-update.json を現行版へ更新
- studio/index.html と apps/studio/index.html を同一内容に同期

## 互換性
既存プロジェクトデータ、戦闘データ、検証結果の形式は変更しない。外部AIサービスおよびネットワーク接続は必須ではない。

## 注意
実際の配布可否は、アプリ内の品質ゲートで代表戦闘、一括検証、AI探索を実行した結果に基づいて判定する。
