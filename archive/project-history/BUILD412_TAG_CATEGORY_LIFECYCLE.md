# BUILD412 タグカテゴリ・ライフサイクル保護

## 目的
BUILD407〜411で整備したタグ受け入れ・索引・置換・削除基盤を、タグカテゴリにも拡張する。

## 実装内容
- データ検証画面にタグカテゴリ・インスペクターを追加
- カテゴリID・名称・説明による検索
- カテゴリ別の所属タグ数と一覧表示
- 所属タグの別カテゴリへの一括移動
- 一括移動前の内容確認、人間承認、直前バックアップ
- 未使用かつ未ロックのカテゴリだけを物理削除可能にする保護ゲート
- 削除時のカテゴリID再入力
- 変更後の保存、索引再構築、再検証、画面再描画

## 変更境界
- 変更対象は `data.tag_categories` とタグ定義の `category_id` のみ
- キャラクター、マスターの `tags` 配列は変更しない
- Save形式、Export形式、PHP Runtime、ゲーム戦闘ロジックは変更しない
- 暗黙の移動、連鎖削除、自動削除は行わない
