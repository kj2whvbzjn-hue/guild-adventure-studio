# Build 469.5 計算カードシステム

## 追加内容

設計カード・参照システムへ「計算カード」を追加しました。

- 計算を複数の行（ノード）に分割して接続
- 各行の有効／無効
- 定数、他カード参照、前の計算行参照
- 加算、減算、乗算、除算、剰余、べき乗
- Min、Max、Clamp、四捨五入、切り捨て、切り上げ、絶対値
- IF、AND、OR、NOT
- Seed付き乱数プレビュー
- ダメージ、命中、回復の雛形
- 保存した結果を `カードID.value` で他カードから参照
- ID／マスターID／タグ／JSON入出力との統合

## 使い方

1. 戦闘計算シミュレーターの「設計カード・参照システム」を開く
2. カード種類で「計算カード」を選択
3. 「ダメージ雛形」「命中雛形」「回復雛形」のいずれかを押すか、計算行を追加
4. 入力A/B/Cに前の行または保存済みカードの値を指定
5. 不要な行は「有効」をOFF
6. 最終出力ノードを選んで保存

## 注意

現段階では計算カードは設計値・参照値を作る機能です。既存戦闘エンジンの物理／魔法計算をこのカードへ完全置換する機能は、後続段階で接続できます。
