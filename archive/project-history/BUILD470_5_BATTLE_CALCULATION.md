# BUILD 470.5 — 戦闘計算パイプライン

## 目的
戦闘シミュレーター内の物理・魔法ダメージ計算を共通パイプラインとして分離し、計算順と中間値を確認可能にする。

## 実装
- 物理ダメージの計算順を共通関数 `calculatePhysicalDamagePipeline` に集約
- 魔法ダメージの計算順を共通関数 `calculateMagicDamagePipeline` に集約
- 戦闘画面に代表値を使った計算パイプライン確認UIを追加
- ダメージトレース有効時に各計算段階を戦闘ログへ出力
- JSONトレース有効時に `damage_pipeline` レコードを出力
- ミス時に `attack_miss` レコードを出力
- 既存の係数設定、戦闘履歴、保存データ形式を維持

## 計算順
### 物理
攻撃基礎 → 威力倍率 → 物理補正 → スキル補正 → 属性補正 → 防御減算 → 乱数 → クリティカル → 耐性 → 被ダメージ軽減 → 最小ダメージ保証

### 魔法
基礎威力 → スキル倍率 → スキル補正 → 魔法武器補正 → 属性補正 → クリティカル → 乱数 → 耐性 → 被ダメージ軽減 → 最小ダメージ保証
