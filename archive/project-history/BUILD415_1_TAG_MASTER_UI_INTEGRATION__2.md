# BUILD415.1 タグマスターUI統合

## 目的

独立したタグ管理メニューが廃止され、マスターデータ画面へ統合されたStudioで、タグ定義を単独で追加・編集・安全削除できるようにする。

## 実装

- マスターデータの分類に「タグ」を追加
- タグ選択時は通常マスターのタグ付与／JSON入力欄を非表示
- タグ専用入力欄を表示
  - ID・名称・説明
  - タグカテゴリ
  - 親タグ
  - 置換先タグ
  - エイリアス
  - 有効・廃止済み・ロック
- タグIDは `TAG-0001` 形式で自動採番
- 保存先は既存仕様どおり `data.tags`
- 一覧にはカテゴリ、親、使用件数、状態、エイリアスを表示
- 削除は既存の `canDeleteTag()` を通し、参照中・子タグあり・置換先利用中・ロック中のタグを拒否
- 選択分類CSVおよび全分類CSVへタグを追加
- 全体ID重複検査へタグIDを追加

## 互換性

- Saveスキーマ変更なし
- Exportスキーマ変更なし
- PHP Runtime変更なし
- BUILD407〜415のタグガバナンスAPIを継続利用
