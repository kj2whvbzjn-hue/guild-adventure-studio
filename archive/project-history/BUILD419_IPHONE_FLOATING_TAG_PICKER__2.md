# BUILD419 iPhone Floating Tag Picker

## 実装内容

- ルールエディターの通常タグ選択を全画面モーダルに変更
- 行全体タップによる選択・解除（トグル）
- チェックボックスおよびダブルクリック操作を廃止
- 複数タグの一括追加
- 上部フローティング領域
  - 検索
  - 検索結果の全選択
  - 選択解除
  - 表示件数／選択件数
- 下部フローティング領域
  - キャンセル
  - 追加件数付き確定ボタン
- 検索対象
  - タグ名
  - ID
  - カテゴリ
  - 親タグ
  - 説明
- 検索候補は最大50件
- 検索条件を変更しても選択状態を保持
- 同一セクションへの同一タグの重複追加を防止
- iPhoneのセーフエリア、慣性スクロール、背景スクロール抑止に対応
- 0件選択時は追加ボタンを無効化

## 操作

1. 配置先を選択
2. 「＋ タグを選択」をタップ
3. 行全体をタップしてタグを選択・解除
4. 必要に応じて検索、全選択、選択解除を使用
5. 下部の「追加（n件）」で確定
