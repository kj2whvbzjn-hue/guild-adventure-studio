# BUILD 470.8 リリース品質ゲート

## 目的
BUILD 470.7までに接続した検証結果を統合し、配布候補としての準備状況を再現可能に判定する。

## 実装
- データ検証、参照整合性、代表戦闘、一括検証、AI探索を5段階チェック
- A〜Dのリリースグレード判定
- データエラーをブロッキング条件として扱う
- 未実行検証を警告として表示
- 統合検証結果とAI探索結果を含むリリース証跡JSONを出力
- 既存データ形式・戦闘計算式・AI探索形式は変更しない
