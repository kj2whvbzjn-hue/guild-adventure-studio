# BUILD420 Project Device Storage Fix

## 修正内容

- プロジェクト一覧を端末内の保存キーから再検出する処理を追加。
- プロジェクト一覧画面に「全プロジェクトを一括出力」「全プロジェクトを一括読込」を追加。
- PCとiPhoneなど別端末間で、全プロジェクトをJSON一括移行できるようにした。
- 同一ID読込時は上書き確認を表示。
- 端末・ブラウザごとに保存領域が異なることを画面上で明示。

## 重要

ブラウザの localStorage は端末・ブラウザごとに独立しています。PCで作成した `test` は自動ではiPhoneへ現れません。
PC側で「全プロジェクトを一括出力」し、iPhone側で「全プロジェクトを一括読込」すると表示されます。
