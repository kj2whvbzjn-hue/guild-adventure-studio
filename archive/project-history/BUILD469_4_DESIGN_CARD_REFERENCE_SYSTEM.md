# Build 469.4 設計カード・参照システム

## 追加機能
- 全カードで表示名、編集可能ID、マスターID、タグを管理
- 比率計算カード（3ステータス×割合×係数）
- 比率結果を別の計算カードの基礎値として参照
- 装備、スキル、キャラクター、編成を独立カードとして保存
- キャラクターから装備・スキルカードIDを参照
- 編成から最大6件のキャラクターカードIDを参照
- 味方／敵編成カードを既存戦闘シミュレーターへ反映
- カード一式のJSON入出力
- localStorageへの自動保存

## 比率例
力6、器用3、知性1、係数2 → 力12、器用6、知性2、合計20

参照名の例：`RATIO_PHYSICAL_001.力`、`RATIO_PHYSICAL_001.total`
