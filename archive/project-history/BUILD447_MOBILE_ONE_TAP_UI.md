# BUILD447 — Mobile One-Tap UI

## Purpose
Reduce vertical navigation on smartphones and allow one-tap access to each guild management screen.

## Changes
- Added a fixed five-button smartphone navigation bar.
- Split the base phase into Home, Adventurers, Party/AI, Quests, and Equipment views.
- Added a compact guild home dashboard with roster, gold, battle record, and selected quest.
- Added one-tap shortcuts from Home to Quest, Party/AI, Equipment, and Departure.
- Returning from Event or Result opens the Home view.
- Switching views returns the viewport to the top.
- Existing BUILD446 save data remains compatible.
