# AI Project Charter

この文書は、AIが本プロジェクトを継続開発するときに最初に確認する基本方針である。
一般的な開発手法より、本書の合意事項を優先する。

## Purpose

開発速度と安全性を両立し、スマートフォン中心の検証サイクルを維持する。

## Rules

- AIはGitHubへ自動デプロイしない。
- AIはPatch ZIPを作成し、Studioで差分を表示する。
- GitHubへの反映は人間の確認と承認後に行う。
- 1つのPatchは1つの目的に限定する。
- ロジック変更と表示変更は可能な限り分離する。
- 開発時はスマートフォン縦型での視認性と検証速度を優先する。
- 正式版のゲーム体験は横型を維持する。
- 正式版UIと演出の本格調整は、主要システム完成後に行う。
- UIは、操作不能・確認不能など開発を妨げる場合に優先修正する。

## Current Phase

Battle Loop Development

戦闘 → 報酬 → 育成 → 再戦の安定化を優先する。
