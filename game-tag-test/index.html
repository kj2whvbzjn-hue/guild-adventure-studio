Battle Core 開発コンソール

検証用デモとして、各Tickで Action Gauge += AGI、Gaugeが100以上になったユニットが行動します。行動後はGaugeを100減算し、余剰Gaugeを保持します。行動可能になったユニットは、まず対象と行動を予約します。予約から数Tick後、対象の生存・敵味方関係・自身の行動可否を再確認してから通常攻撃を実行します。対象が倒れていた場合は対象を変更せず、固定対象無効として予約を失敗させます。HPが0になると戦闘不能になり、片方が全滅すると戦闘を終了します。MP・Cooldown・疲弊は次ビルド以降です。

タグスキル Sprint 4 検証（タグ検証）

ATTACK・DOTに加え、単体BUFF／DEBUFFを複数スタックとして保持し、同一能力値では最高強度だけを実効値へ反映します。各スタックの独立終了、最高値終了後の次点切替、全終了後の原値復帰をJSONで検証します。

各検証は通常AI・行動ゲージ処理を停止します。BUFF／DEBUFF最高値検証はTick 0・100・200に強度10・30・20を付与し、実効値が10→30→20→0へ切り替わることを確認します。複数対象・死亡制御に加え、本BuildではStudioの正式出力 Export/skill/skills.json を読み込み、タグ定義を同一ランタイムへ接続します。連携攻撃まで含む正式データの読込・コンパイル・ID一致をJSONで検証します。正式運用回帰検証では、必須スキルがすべてStudio出力由来であること、全Studioタグ定義がコンパイル可能であること、固定埋込定義が正式運用対象へ混入していないことに加え、Studio正式SHIELDの単体吸収・全体付与・FIFO・期限終了・戦闘終了消去を確認します。
