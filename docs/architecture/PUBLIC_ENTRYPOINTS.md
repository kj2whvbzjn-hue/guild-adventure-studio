# Public entrypoints — BUILD427

GitHub Pagesで維持する公開入口です。

| URL | 役割 | 互換性 |
|---|---|---|
| `/index.html` | ゲーム本体 | 従来通り |
| `/studio/` | Studio本体 | 従来通り |
| `/apps/` | 分類後の共通案内 | BUILD427で追加 |
| `/apps/game/` | ゲームへの互換入口 | `/index.html`へ転送 |
| `/apps/studio/` | Studioへの互換入口 | `/studio/`へ転送 |

`/apps/` は管理しやすくするための案内ページです。ゲーム本体やStudio本体の実装位置はまだ変更していません。
