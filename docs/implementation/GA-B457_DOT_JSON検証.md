# GA-B457 DOT JSON検証

## 変更範囲

- Studio: GKS-B473（変更なし）
- 既存ゲーム `game/`: GA-B455（変更なし）
- タグ検証ゲーム `game-tag-test/`: GA-B457

## 追加機能

- 検証専用1000 Tick実行
- 検証中の通常AI・行動ゲージ処理停止
- ATTACK、DOT付与、DOT周期ダメージ、DOT終了の構造化イベント記録
- JSONログの自動ダウンロード
- 現在の検証ログの再出力
- JSON内で期待値と実測値を比較しPASS/FAILを出力

## 操作

1. 開発者モードを有効化する。
2. 戦闘画面のBattle Core開発コンソールを開く。
3. `毒斬り（DOT実装確認）`、使用者、十分なHPを持つ対象を選ぶ。
4. `1000 Tick検証`を押す。
5. 通常AIを挟まず、Tick 0から1000まで検証が進む。
6. JSONファイルが自動出力され、画面にPASS/FAIL要約が表示される。

## 期待値

- ATTACK: 1回
- DOTスタック付与: 1
- DOT発生: Tick 100から1000まで10回
- DOT単発: 20
- DOT合計: 200
- Tick 1000で終了
- 通常AI行動: 0
- 最終アクティブスタック: 0
