# GA-B458 DOT複数スタック・上限検証

## 目的
GA-B457で確認済みの単一DOTスタック処理を拡張し、再付与時の独立スタック追加と最大スタック到達時の付与拒否をJSONで検証する。

## 変更範囲
- Studio: 変更なし（GKS-B473）
- 既存ゲーム `game/`: 変更なし（GA-B455）
- タグ検証ゲーム `game-tag-test/`: GA-B458

## 追加機能
- `5スタック＋上限検証` ボタン
- 毒斬りをTick 0で6回実行
- 最初の5回は個別DOTスタックとして追加
- 6回目は `MAX_STACK` として拒否
- 拒否イベント `dot_stack_rejected` をJSONへ記録
- 検証対象HPを5000へ一時拡張し、全スタックを1000 Tick完走
- 未実行・入力空・Tick不足をPASSにしない厳格判定

## 期待結果
- ATTACK: 6回
- DOT追加: 5スタック
- DOT拒否: 1回
- DOT Hit: 50回（5スタック × 10回）
- DOT合計: 1000（20 × 50回）
- DOT終了: 5回
- 終了時アクティブDOT: 0
- 通常AI行動: 0

## 実機確認
1. `/game-tag-test/?v=458` を開く。
2. 開発者モードを有効にする。
3. 戦闘画面のタグスキル検証パネルを開く。
4. `毒斬り（DOT実装確認）` を選ぶ。
5. `5スタック＋上限検証` を押す。
6. 自動ダウンロードされたJSONの `summary.passed` が `true` であることを確認する。
